# [2379. 得到 K 个黑块的最少涂色次数](https://leetcode.cn/problems/minimum-recolors-to-get-k-consecutive-black-blocks/description/)

题目：

给你一个长度为 n 下标从 0 开始的字符串 blocks ，blocks[i] 要么是 'W' 要么是 'B' ，表示第 i 块的颜色。字符 'W' 和 'B' 分别表示白色和黑色。

给你一个整数 k ，表示想要 连续 黑色块的数目。

每一次操作中，你可以选择一个白色块将它 涂成 黑色块。

请你返回至少出现 一次 连续 k 个黑色块的 最少 操作次数。

示例：
---
    输入：blocks = "WBBWWBBWBW", k = 7
    输出：3
    解释：
    一种得到 7 个连续黑色块的方法是把第 0 ，3 和 4 个块涂成黑色。
    得到 blocks = "BBBBBBBWBW" 。
    可以证明无法用少于 3 次操作得到 7 个连续的黑块。
    所以我们返回 3 。


```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        s = 0 # 综合
        ans = inf # inf表示 int 的最大值
        for i, block in enumerate(blocks): # 牢记enumerate
            s += 1 if block == 'W' else 0 # 三元运算符 x if xx else

            left = i - k + 1 # 计算左边的坐标
            if left < 0: # 如果左边坐标小于0 0 则窗口小
                continue
            
            ans = min(ans, s) # 窗口满了以后每次都更新 ans 的值

            s -= 1 if blocks[left] == 'W' else 0 # 如果出窗口的值不是白色，则 s 减 0
        return ans
```

灵神版本
* python以外的代码优化思路： s[i] & 1， 其意思是减少判断语句的开销， 因为 "W" 和 "B" 分别可以看作对应 1 和 0 ，因为这恰好是它们 ASCII 码二进制最低位的值。
```python
class Solution:
    def minimumRecolors(self, blocks: str, k: int) -> int:
        ans = cnt_w = blocks[:k].count('W') # 通过 python 的切片以及 count 函数求解出初始 k 窗口中的 W 数量，即初始窗口的所有 W 都转为 B 
        for in_, out in zip(blocks[k:], blocks): 
            '''
            一个巧妙的处理， 通过 zip 强行构造一个数组遍历, 其中 zip 函数的定义如下：
            将多个可迭代对象（如列表、元组等）“压缩”在一起，返回一个由元组组成的迭代器。每个元组包含来自各个可迭代对象的对应元素。
            其中， 长度不一致时， 将以最短的长度为终止
            '''
            cnt_w += (in_ == 'W') - (out == 'W')
            ans = min(ans, cnt_w)
        return ans
```
